# 📸 AI Photo Upscaler & Face Restorer Pro

A professional GUI application built with **Python**, **CustomTkinter**, **Real-ESRGAN**, and **GFPGAN** to enhance, upscale, and restore low-resolution photos and faces.

## ✨ Features
* **4x Image Upscaling:** Enhances background, clothes, and body details.
* **AI Face Restoration:** Restores facial details using GFPGAN v1.4.
* **Interactive Viewer:** Zoom in/out with mouse wheel and drag to scroll.
* **Customizable UI Themes:** Easily change button colors and styles.

## 🚀 How to Run
1. Run `run_app.bat` to automatically set up the environment and launch the app.
2. Or build a standalone folder executable using `build_exe.bat`.
